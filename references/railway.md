# 铁路票快速合成

先读取 [票根版式与文案](ticket-layout.md)。飞机票和铁路票共享主副券布局，仅交通图标不同。

本文件用于默认快速生成：把交通图标要求、逐字文字清单与原图简化、艺术化重绘、票根排版合并到同一次图像编辑调用。不要要求预先生成无字画作；只有用户明确要求查看过程时才切换到分阶段模式。

右侧副券顶部使用略放大的淡金线描火车图标，宽约副券内部宽度 55–65%，不能出现飞机或其他交通图标。图标不得遮挡文案。

逐字文字清单（替换方括号，不印占位符）：

- 行旅手记
- 起点：[用户起点]
- 终点：[用户终点]
- 出发日期：[仅日期，不含时刻]
- 把日子交给远方
- 副券中间：[最终选定的默认三行或用户纪念文案，按 ticket-layout.md 排版]
- 愿每次出发，都有新的遇见

默认中间三行：一城风物 / 一程山水 / 一页珍藏。自定义时全部替换；单段文案保持为一个连续文本块，仅自然换行。长度增加时先换行再适度缩小字号，保证清晰，不删改文字。

禁止“沿途所见”“路线”“时间”、具体时刻、任何乘车凭证提示、纪念票大标题、票号、条码和二维码。不添加票价、车次、航班或个人信息。
