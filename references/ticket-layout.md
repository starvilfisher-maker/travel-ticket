# 行旅手记：默认票根版式

这是用户选定的创意版式，不是实物车票复刻。只参考该布局，不复用测试湖景或上海杭州等演示字段；实际画作必须来自用户图片。

## 视觉结构

- 横向长条票根，宽高约 2.3–2.6:1。暖米白纸，深墨绿双线外框与细金线，四角圆润。
- 外侧左右和四角保持完整，仅主副券分割线上下各一个小半圆缺口；无锯齿或多余挖口。
- 主券约占 78%，艺术化图景柔和铺满整个主券并自然延展到文字区，不把画面裁成左侧矩形。主券文字直接叠印在画作上：排“起点 / 终点”和两地大字，中间短横线相连；其下“出发日期”及年月日。
- 虚线左侧全部文字（含左上“行旅手记”和底部“把日子交给远方”）使用较浅、略带透明感的墨绿色，像纸面淡墨套印；保持清晰可读，但不能形成厚重实色色块或遮住主体。优先把文字放在水墨留白、天空、湖面等低细节区域，必要时轻微降低其正下方画面浓度，不使用不透明底板、白框或文字阴影。
- 主券左上小号“行旅手记”，底部“把日子交给远方”。不出现“路线”、具体时刻或凭证提示。
- 右侧副券约占 22%，细虚线分隔。右上为淡金线描交通图标：横向视觉宽度约为副券内部宽度的 55–65%，较原稿放大约 20%，留足上下间距；飞机用清晰飞机剪影/线描，铁路用简洁火车轮廓，不用品牌标志。
- 副券中间为三个文案段落，默认“一城风物”“一程山水”“一页珍藏”，段间细圆点或适量留白。副券底部固定小字“愿每次出发，都有新的遇见”。

## 自定义纪念文案

自定义内容替换副券中间的全部三个默认段落，不替换起终点、日期、左上眉题、主券底部或副券底部寄语，除非用户另行指定。

- 未提供或仅空白：使用默认三行。
- 用户明确给出三个非空段落：作为三个段落，保留语序、标点和段落关系，可在段间使用细圆点。
- 用户输入一段连贯文字：必须作为一个连续段落排版，只按副券宽度自然换行，不擅自拆成三个语义段落，不在换行之间添加圆点、分隔线或其他符号。标点、字词及顺序逐字保留。
- 一段文字自然换行后超过三行时，保持为同一个连续文本块并逐步缩小字号、行距；不得为了套用默认结构将其合并或重分成三段。用户明确要求固定换行时尊重原换行。
- 短文案用接近默认字号；长度增加时先自然换行，再适度减字号和段间距，每段允许两行或更多。不要拉伸/压扁字形，不越过副券边界，不用省略号删文案。
- 以成品长边约 1800px 为参考，默认副券主体字约 34–42px；较长文案可降至约 26–32px，通常不低于 24px。其他分辨率按比例调整。这是图像提示词目标，不是精确像素保证，必须查看实际输出。
- 最终字块与图标、底部寄语之间保持明显空隙。若完整文案必须缩到难以阅读才放得下（如长段落），在生成前请用户缩短或允许扩大副券；不擅自删字。建议总长度约 12–48 个汉字，长一些也应先评估排版，不按字符数机械拒绝。
- 起终点长地名同样先换行再缩字，不能裁掉内容。

## 最终提示词

把原图艺术化要求、所选票类图标及本文件的布局规则组合为一次快速合成提示词。明确分开“原图与艺术方向”“布局约束”“逐字文字清单”。文字清单要包含最终拆分后的纪念文案，不得同时保留默认三行与用户文案。全部占位符替换后再调用。
