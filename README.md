# travel-ticket · 旅行纪念票根

把一张旅行照片、起点、终点、日期和票类交给 Codex，先简化画面，再水墨化或油彩化，生成属于你的飞机或铁路纪念票根。

主视觉是从照片提炼的抽象编辑插画，不是直接贴照片或套滤镜。减少细节后，以水墨浓淡留白或油彩概括笔触重新绘制，加入纸张质感、交通图标和票根分隔线。默认采用行旅手记横版设计，支持自定义副券纪念文案。

## 运行条件

- 本地安全保存脚本使用 Python 3.9 或更高版本，无第三方依赖。
- 在支持 skills 且可使用内置 `image_gen` 图像工具的 Codex 环境中运行。
- 此技能本身不附带图像模型，不会为缺少图像工具的环境增加图像生成能力。
- 内置图像工具不需要为本技能额外配置 API 密钥，仍受宿主账号的工具可用性与用量限制约束。
- GitHub 仅存放与分发技能，不提供网站、服务器或图片生成 API。

## 安装

将整个仓库克隆为 Codex 技能目录中的 `travel-ticket` 文件夹（若目录已存在，先检查已有内容，不覆盖）：

```sh
git clone https://github.com/starvilfisher-maker/travel-ticket.git "${CODEX_HOME:-$HOME/.codex}/skills/travel-ticket"
```

本地源码也可以整体复制到该目录。确认目录内直接包含 `SKILL.md`，随后重新打开 Codex 会话以加载技能。

## 使用

上传照片或提供可读的本地图片路径，然后输入：

```text
请用 $travel-ticket 制作票根。
起点：上海
终点：杭州
日期：2026年8月31日
票类：铁路票
风格：水墨
纪念文案：愿一路有风景，也有好心情。
```

“风格”和“纪念文案”可选，其他项缺失时先集中提示补充，收到回复后才开始生成。单个地点视为终点，需补充起点。日期含时刻时仅显示日期。

## 已选定样式：行旅手记

- 保留水墨或油彩艺术画作、温暖纸面与留白，配墨绿金线外框；仅上下两个小缺口。
- 主券显示起点、终点和出发日期，不显示“路线”、具体时间、纪念票大标题或凭证提示。
- 右侧图标根据票类切换为火车或飞机，并适度放大；其余布局保持一致。
- 副券默认三行：“一城风物 / 一程山水 / 一页珍藏”。
- 可自行填写一段纪念文案，替换右侧默认三行；单段内容保持为一个连续文本块，仅按宽度自然换行，不会替换其他位置的固定旅行短句。
- 主券画作铺至副券虚线，起点、终点、日期等文字以浅墨色半透明叠印在画面低细节区域，避免遮挡人物、建筑等核心主体。

### 文案长度与排版

短文案使用较大字号；长文案作为一个连续文本块自然换行，再减小字号和行距，保留完整原文、顺序和标点，不擅自拆成三段或加入分隔点。建议 12–48 个汉字，但并非硬上限；约 80 字内容也会先尝试自适应。若内容过长、无法保证可读性，会先请用户缩短或允许扩大副券，不擅自截断、改写或缩成难辨小字。留空则使用默认三行。

例如，可替换为：

```text
纪念文案：与你走过的每一座城，都藏着值得珍惜的故事，愿下一程仍有你同行。
```

## 处理与输出

默认在一次图像编辑中完成画面简化、艺术化重绘和 票根融合，只输出最终票根。成品存在明确问题时才追加一次针对性修正。photo-abstract-editorial 是画面提炼方向，不依赖同名插件。

成品位于当前工作区的 `output/travel-ticket/`。默认不生成中间图；只有用户明确要求查看过程时，才切换到分阶段模式并保存到 `intermediates/`。回复仅提供最终票根预览与文件链接；重名生成新版本，不覆盖原图或旧结果。

原照片中已有的品牌、店招和环境文字默认作为画面内容保留，不主动清除；AI 艺术化可能使很小的字形发生变化，无法保证印刷级复现。

## 质量与隐私

AI 渲染无法保证每次都精确复现中文字形或照片细节。技能会检查最终结果，默认最多追加一次针对性修正；仍有问题时明确指出，不将结果描述为已完全校验。若需要印刷级文字精度，应另行选择程序排版方案。

图片会交由当前 Codex 内置图像工具处理，并非离线生成。技能不会把照片、生成结果或凭据上传至 GitHub。仓库忽略常用素材、输出和凭据路径；公开提交前仍需人工检查，忽略规则并不能识别所有私人文件。

图像工具不可用时会说明原因，不自动切换外部付费 API。

## 仓库结构

- `scripts/save_output.py`：排他创建输出文件，重名自动增加版本号，不修改图像。
- `SKILL.md`：输入、生成、检查与交付流程。
- `agents/openai.yaml`：Codex 展示信息与调用入口。
- `references/ticket-layout.md`：票根布局、图标与自定义文案自适应排版规则。
- `references/art-direction.md`：简洁化与水墨、油彩艺术指导。
- `tests/validate_skill.py`：使用 Python 标准库检查结构、引用和保存行为。
- `references/airplane.md`、`references/railway.md`：按需加载的渲染模板。

仅用于旅行收藏与创意分享，不作为订票、报销、登机或乘车凭证。
